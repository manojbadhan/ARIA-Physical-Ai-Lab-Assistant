# User manual

**Student:** sign up, open *Ask ARIA*, type or press the mic. Say "where is the multimeter?" for a tool location. Press *Start camera* then *Identify* to name an object. *Inventory* lists every tool and where it is.

**Faculty:** sign up as faculty, open *Faculty*. Upload a photo of a box, enter almirah/rack/box, save. Students using tools appear on the right.

Switch light/dark with the button at the top right.
